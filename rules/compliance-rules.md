# 적용 판단·검토 규칙

이 도구는 담당자의 안내 정정 검토를 지원한다. 개인 수급 판정·기관의 공식 법률 판단·외부 게시를 자동화하지 않는다.

- 공포일을 시행일로 간주하지 않는다. 부칙·경과조치·자료 대상 시기를 확인한다.
- 조례·시행규칙·연도별 공고의 충돌은 일률적인 우선순위로 해결하지 않는다. 위임·적용 근거를 확인한다.
- 근거 미확인과 미적용을 구분한다. 미확인 건을 제외해 검사 성공률을 높이지 않는다.
- 시행 예정 초안은 계획 자료다. MVP에서는 적용 기준일이 도래한 새 회차를 검토하기 전 승인하지 않는다.
- 승인에는 최신 회차·확인된 연결·적용 판단·유효 인용·근거 재확인·담당자·사유가 필요하다.
- APPROVED는 정정안 승인, VERIFIED는 실제 수정 확인이다. 화면·보고서에서 용어를 섞지 않는다.
- 출처·초안·판단이 바뀌면 새 버전/회차를 만들고 과거 승인 이력은 보존한다.
  APPROVED 이후 예상 안내 수정은 별도 확인 증거로 분리하며, 다른 근거가 그대로일 때 기존 회차를 VERIFIED로 종료한다.
- 외부 수정은 자료 관리자가 수행한다. 재수집과 사람의 확인 없이 “수정 완료”라고 표시하지 않는다.
- 실제·가상 사례를 명시한다. API 문서 열람을 실수집·실증·업무 성과로 표현하지 않는다.
- 출처의 이용허락을 다른 링크·첨부까지 확대하지 않는다. 불필요한 개인정보를 수집하지 않는다.
- 로컬 시연 역할은 인증·기관 권한을 뜻하지 않는다. 실제 배포의 인증·보존·보안 기준은 별도 확인한다.

정확한 전이·불변식은 [도메인 모델](../docs/05_domain-model.md), 미확정 역할은 [기초설계](../docs/superpowers/specs/2026-11-17-ordinance-impact-design.md#11-미결정-사항과-담당), 검증 방법은 [검증 계획](../docs/08_validation-plan.md)을 기준으로 한다.
