# 데이터 규칙

정의와 상태의 원본은 [도메인 모델](../docs/05_domain-model.md), 출처별 확인 범위는 [조사 문서](../research/ordinance-impact-sources.md)다.

1. 원문 URL·제공기관·관할·관측 시각·원문/텍스트 해시·파서 버전을 보존한다.
2. 스냅샷은 불변이다. 정규화·수동 보정·새 수집이 원문을 덮어쓰지 않는다.
3. 법규는 내부 ID와 외부 ID 이력을 분리한다. 동명·개칭·이전 연혁을 이름만으로 병합하지 않는다.
4. 복지 API의 근거법령명은 연결 후보다. wlfareInfoDtlCd를 법규 ID로 취급하지 않는다.
5. 조례–사업·사업–안내자료 연결은 근거를 가진 확인 버전으로 저장한다.
6. 공포·시행·사업 운영 기간·안내 대상 시기·수집일을 서로 대체하지 않는다.
7. 부칙·별표·위임 규정이 필요한데 없으면 누락으로 기록한다. 원문에 없는 내용을 채우지 않는다.
8. 인용은 고정 텍스트의 코드 포인트 구간·정확한 인용문·해시로 검증한다.
9. 등록 대상 전체와 완료·실패·미검사 분모를 보존한다. 검색 누락을 영향 없음으로 세지 않는다.
10. 실제/가상/기존 캐시를 구분한다. 기존 이음등 자료는 새 주제의 수집·평가 성과가 아니다.
11. API 키·인증 토큰·개인 신청서·상담자료는 스냅샷·모델·로그·커밋에 넣지 않는다.
12. 실패 응답은 정상 원문이 아니다. 과거 자료 사용 시 기준일과 최신성 제약을 표시한다.

보존 기간·기관별 접근 정책은 미확정이다. 공개 원문도 무기한 보관이 허용된다고 가정하지 않으며, 실제 수집 전에 출처별 조건을 확인한다.
