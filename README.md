# 조례 개정에 따른 복지정보 변경 영향 추적 및 안내 오류 예방 AI

조례가 개정되면 영향을 받을 복지사업과 안내자료를 찾고, 변경 근거와 정정 초안을 담당자에게 제시하는 업무 도구의 기초설계다.

**브랜치:** `design/ordinance-change-impact` · **상태:** 기초설계 v0.1 · **작성일:** 2026-11-17

## 핵심 흐름

```mermaid
flowchart LR
    A[조례 이전·개정 버전 확보] --> B[조문·조건 변화 추출]
    B --> C[연결된 복지사업 확인]
    C --> D[등록 안내자료 영향 비교]
    D --> E[담당자 정정안 검토]
    E --> F[실제 수정 후 재확인]
```

공포일·시행일·부칙의 적용 조건을 구분한다. 근거가 부족한 건은 확인 요청으로 남기며, AI가 외부 안내문을 자동으로 수정하거나 법적 적용을 확정하지 않는다.

초기 목표는 **한 지자체·복지사업 10개·조례 버전쌍 10개·안내자료 20개**다. 확보된 데이터 수나 달성 성능을 뜻하지 않는다. 먼저 실제 조례–사업–안내자료 연결 3건을 확보해 진행 가능성을 검증한다.

## 기존 프로젝트와의 관계

이음등과 별도 주제다. 기존 `prototype/` 코드는 이음등 시제품이며 새 서비스 구현은 아직 없다. 기존 실행 명령과 서버를 사용해도 이음등 화면이 열린다.

- [기존 이음등 기획](docs/기획구상안.md)

새 구현은 향후 `prototype/ordinance_impact/`에 분리한다. 이 브랜치에서는 설계 문서만 작성했다.
