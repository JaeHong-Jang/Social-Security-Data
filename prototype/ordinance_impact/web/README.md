# 조례 변경 영향 검토 — 화면 시제품

실제 화면을 검토하기 위한 독립 React 앱이다. 모든 조례·사업·원문·정정안·수집 상태는 **가상 예시**다.
기준일은 2026-11-17이며 실제 법적 적용, AI 분석 결과, 외부 안내문 정정을 뜻하지 않는다.

## 실행

이 폴더에서 Node 24 환경으로 실행한다. 저장소 기존 웹과 같은 라이브러리·잠금 버전을 사용한다.

~~~sh
npm ci
npm run dev
~~~

주소: http://127.0.0.1:5175/ — 기존 이음등 화면의 5174와 분리한다.

## 볼 수 있는 화면

- 변경 검토: 6개 사례, 분류 탭·사업 검색·부서 필터·가상 보고서 저장
- 근거 비교: 개정 전/후 조문과 현재 안내문, 부칙·날짜·사업 연결
- 정정안 검토: 초안 열람 후 확인·승인, 시행 예정·근거 부족의 승인 차단
- 수정 확인: 승인과 별도의 가상 후속 안내문 확인·이력
- 연결 관리, 출처·수집 범위, 검토 이력

문구를 자유 편집하면 추가 근거 검토가 필요하므로 시연에서는 승인을 보류한다.
“예시 초안 복원” 후 확인란을 선택하면 준비된 가상 초안의 승인 흐름을 볼 수 있다.
원문과 판단은 실제 기관 자료가 아니며 새로고침하면 시연 상태가 초기화된다.

## 검증

~~~sh
npm test
npm run build
npm run test:ui
~~~

test:ui는 실행 중인 서버와 설치된 Chrome을 사용한다. 다른 Chromium 경로는 PW_CHROMIUM,
서버 주소는 BASE_URL로 지정할 수 있다. 브라우저를 자동으로 다운로드하지 않는다.

- 규칙 테스트: 15개
- 브라우저 검사: 36개 — 승인/수정 확인, 미래·근거 부족 차단, 원문 대화상자,
  초안 복원, 보고서, 목록·연결·출처·이력, 1440/1024/390/360px의 주요 화면
- 표본 텍스트 대비와 페이지 가로 넘침 검사. 전체 WCAG 적합성 인증을 뜻하지 않는다.
- 브라우저 검사 결과·상태별 캡처는 로컬 artifacts/에 저장한다.
