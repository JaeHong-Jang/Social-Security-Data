화면: **http://127.0.0.1:5175/data**. API: `127.0.0.1:8788`.
기존 이음등(5174/8787)과 별도로 실행한다. 데이터·원래 관측일·현재 시각·법규 시행일을 구분한다.

사업 총 5,289건은 지자체+중앙부처의 식별자로 합친 목록이며, 최신 전국 전체 사업 수를 뜻하지 않는다.
조례 3쌍은 공식 연혁의 인접 버전 ID와 각 실제 본문을 함께 확보한 경우에만 표시한다.
사업–법규–안내 관계는 **검토 후보**다. 전국 조례를 모두 모았거나 안내 오류를 입증한 상태가 아니다.
통계 수급권자 수는 실제 수급자·개정 영향인구와 같은 개념이 아니다.

API·법규 제공 항목의 최초 조사는 [출처 조사](../../research/ordinance-impact-sources.md), 실제 URL·응답·이용조건·실패 기록은 [실연결 조사](../../research/ordinance-impact-live-sources.md)에 있다.

## 실행

저장소 루트에서 기존 Python 가상환경을 사용한다. 새 의존성은 추가하지 않았다.

```sh
.venv/bin/python -m prototype.ordinance_impact.api.collect
.venv/bin/python -m prototype.ordinance_impact.api.server
```

별도 터미널에서 웹을 실행한다.

```sh
cd prototype/ordinance_impact/web
npm ci
npm run dev
```

기존 캐시만 수입하거나 보존된 원문을 유지하는 오프라인 실행:

```sh
.venv/bin/python -m prototype.ordinance_impact.api.collect --offline
```

다른 저장 위치는 수집기의 `--output`과 서버의 `ORDINANCE_DATA_DIR`를 같은 경로로 설정한다.
등록 출처는 [sources.json](sources.json)에서 관리한다. 임의 외부 URL을 서버가 받아 수집하는 API는 제공하지 않는다.

## 인증과 실패

이 체크아웃에는 인증키가 없다. 복지 API 최신 목록 수집은 환경변수 `DATA_GO_KR_KEY` 또는 저장소 루트 `.env`에 설정한 경우에만 수행한다. [설정 예시](.env.example)에 실제 키를 넣어 커밋하지 않는다. 이미 URL 인코딩된 포털 키와 디코딩 키 둘 다 처리한다. 페이지가 불완전하거나 인증/한도 오류이면 기존 자료를 유지하고 실패를 기록한다.

국가법령정보 **전용 인증 API 어댑터는 구현하지 않았다**. 법규 원문·연혁·상위법은 실제로 접근 가능한 공식 공개 웹에서 수집한다. 공개 웹 내부 경로는 구조가 바뀔 수 있어 문서 식별자·정식명·실제 조문을 검증한다. 별표·모든 첨부·전국 감시를 보장하지 않는다.

통계는 포털의 정상 다운로드 준비→사람 확인 필요 여부 검사→공개 파일 다운로드 순서를 따른다. 캡차/차단은 우회하지 않는다. 실패한 재수집이 이전 정상 자료나 원래 관측시각을 덮어쓰지 않는다.

## 보존과 화면

- `data/ordinance_impact/`에 catalog, 불변 원문, 추출문, 스냅샷 메타데이터를 로컬 보존한다. 원문·환경파일은 git에서 제외한다.
- SHA-256으로 보존본과 추출문을 각각 검증한다. 같은 내용의 재수집도 관측 메타데이터는 구분한다.
- 복지로 HTML에는 불필요한 내부 작성자 메타데이터가 있어 **공개 안내 필드만 JSON으로 보존**한다. 수신 HTML의 해시와 추출 보존본의 해시를 구분하며 원 HTML은 저장하지 않는다.
- `/data`는 실제 읽기 전용 자료다. `/data/services/:id`에서 근거와 첨부 링크, 관련 원문을 연다. 실제 연혁 비교는 `/data/compare/ordin-1957377` 등에서 볼 수 있다.
- `/impacts`·`/links`·`/sources`·`/history`는 기존 **가상 검토 시연**이다. 실제 자료를 가상 승인 상태로 가져오지 않는다.
- AI 변경 분석, 적용 시점 확정, 실제 정정안 승인, 기관 인증, 외부 게시와 업무 효과 평가는 구현 전이다.

## 읽기 API

접두사 `/api/ordinance-impact` 아래 `GET /health`, `/catalog`, `/services`, `/services/{id}`, `/documents/{id}`, `/snapshots/{id}`.
사업 검색은 `query`, `kind=all|local|central`, `region`, `legalOnly`, `page`, `pageSize`(최대100)를 지원한다.
API가 꺼져 있으면 화면은 오류·재시도를 표시하며 가상 자료로 대체하지 않는다.

## 검증

저장소 루트에서:

```sh
.venv/bin/python -m pytest prototype/ordinance_impact/api/tests -q
```

웹 디렉터리에서 실행 중인 서버와 설치된 Chrome을 사용한다.

```sh
npm test
npm run build
npm run test:data
UI_DATA_MODE=mock npm run test:data
npm run test:ui
```

실제 API 검사는 현재 연결 자료와 보존본 해시를 확인한다. mock 검사는 네트워크 대역 응답으로 503·빈 상태·페이지·잘못된 연혁쌍을 점검하며 실수집 실적으로 세지 않는다. 전체 WCAG 적합성·법률 정확도·AI 성능 평가를 뜻하지 않는다.
