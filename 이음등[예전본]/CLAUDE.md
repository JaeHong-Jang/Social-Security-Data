# 사회보장 AI 경진대회 — 프로젝트 하네스

「2026 사회보장 데이터를 활용한 AI 혁신 아이디어 경진대회」(한국사회보장정보원·대구가톨릭대 주최) 출품 프로젝트.
**서비스:** 상담 안내만 받고 종결된 위기가구를 AI가 다시 찾아, 읍면동 공무원에게 "누구부터, 왜, 무엇을 들고" 다시 찾아갈지 근거와 함께 알려주는 웹 도구. 서비스 이름은 **이음등**이다. 슬로건: "다시 찾아갈 곳을 밝히고, 필요한 지원을 잇다." 상징은 작은 빨간 램프다. 옛 가칭 '안내종결'은 이제 쓰지 않으며, 정보원의 '이음AI'와 다른 서비스임을 설명할 때 분명히 한다.
**기획 원본:** `docs/기획구상안.md`. 기획과 충돌하는 결정을 할 때는 먼저 이 문서를 고친다.

## 팀 구조 (에이전트)
메인 Claude는 **오케스트레이터**다. 작업을 쪼개 아래 에이전트(`.claude/agents/`)에 맡기고, 결과를 검증한 뒤 합친다.

| 에이전트 | 맡는 일 | 산출 위치 |
|---|---|---|
| `researcher` | 웹 조사, 통계·사실 검증, 경쟁작 분석 | `research/` |
| `designer` | 디자인 토큰, 화면 설계, 시각 검수 | `design/` |
| `frontend` | 웹 대시보드 구현 | `prototype/web/` |
| `ai-engineer` | Ollama 파이프라인 F1~F3, 프롬프트, API | `prototype/{pipeline,llm,prompts,api}/` |
| `data-engineer` | 공공데이터 수집, 가상 가구·메모 생성 | `data/`, `prototype/scripts/` |
| `evaluator` | 테스트셋 관리, 측정, 수치 보고 | `eval/` |
| `proposal-writer` | 제안서 원고, 발표 대본 | `docs/`, `submission/` |
| `judge` | 심사위원 관점의 비판 리뷰. 읽기만 한다 | 리뷰 결과는 답변으로 돌려준다 |

- **GPT(Codex) 서브에이전트:** 아이디어 발산과 교차 조사에 쓴다. 호출은 `omc ask codex -p "..."`이고, 결과는 `.omc/artifacts/ask/`에 저장된다. 결과는 반드시 Claude가 사실을 검증한 뒤에 쓴다.
- **작성과 검토를 분리한다.** 만든 에이전트가 자기 결과를 승인하지 않는다. 검토는 `judge`(기획·제안서)나 `evaluator`(수치)가 한다.
- 진행 상태는 `.fablize/`(goals.py)에서 관리한다.

## 규칙
1. **사실과 수치:** 제안서와 화면에 들어가는 모든 통계에는 출처 URL을 붙인다. 확인하지 못한 수치는 "미확인"으로 표시하고 쓰지 않는다. 확인된 핵심 수치는 `docs/기획구상안.md` §2에 있다.
2. **비밀:** `.env`의 `DATA_GO_KR_KEY`는 출력, 로그, 커밋, 외부 요청 본문 어디에도 넣지 않는다. 코드에서는 파일에서 읽기만 한다.
3. **개인정보:** 실제 개인 데이터는 쓰지 않는다. 발굴 이력과 상담 메모는 모두 가상 데이터이며, 화면에 "가상 데이터" 표시를 한다.
4. **LLM:** Ollama(로컬, 폐쇄망 원칙)를 쓴다. Ollama는 Windows에 설치돼 있다. WSL에서는 `localhost`가 아니라 기본 게이트웨이(`ip route`의 default, 현재 172.20.32.1)의 11434 포트로 접속하며, 이 주소는 재부팅하면 바뀔 수 있다. 환경변수 `OLLAMA_HOST`가 있으면 그 값을 우선 쓴다. 설치된 모델: ax4-light:q4_K_M(A.X 4.0 Light, 한국어 특화), qwen2.5:7b, qwen3:4b-instruct-2507-q4_K_M, gemma2:9b. GPU는 RTX 2080 SUPER 8GB이므로 7~8B 양자화 모델을 쓴다. 메모 생성 모델과 분류 모델은 서로 다른 모델로 한다(순환 평가 방지).
5. **AI 원칙:**
   - AI는 재검토 대상을 **추가하는 방향으로만** 쓴다. 자격 판정, 탈락 처리, 자동 발송은 하지 않는다.
   - 점수에는 성별·나이·국적을 넣지 않는다.
   - LLM 출력에는 원문 근거 인용을 붙인다.
   - 지원 후보는 API 원문 조건으로 뒷받침하고, 최대 3개까지만 보여준다. 후보 0개도 허용한다.
6. **평가 데이터 격리:** `eval/testset/`은 개발과 프롬프트 튜닝에 쓰지 않는다. 쓴 사람은 라벨을 모르는 상태로 작성한다.
7. **디자인:**
   - 따뜻한 베이지 바탕에 정보원 톤의 주색을 쓴다. 빨간 사이렌은 "긴급" 가구에만 쓰며, 경보 피로를 막기 위해 화면 곳곳에 남발하지 않는다.
   - 정보원 로고는 사용 근거를 확인하기 전까지 넣지 않는다.
8. **완료 기준:** 웹 화면은 실제 브라우저에서 띄워 눈으로 확인한 뒤 완료로 본다. 수치는 `eval/results/`의 파일이 있어야 인정한다.
