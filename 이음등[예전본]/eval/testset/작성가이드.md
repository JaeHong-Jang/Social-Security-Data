# 평가용 상담 메모 30건 작성 가이드

AI가 상담 메모를 얼마나 정확히 읽는지 재기 위한 **시험지**를 만드는 작업이다.
메모를 쓰는 데 1시간, 정답을 표시하는 데 30분 정도 걸린다.

---

## 0. 진행 순서
1. `테스트메모_양식.csv`를 엑셀로 연다.
2. **메모 30건을 먼저 모두 쓴다.** 이 단계에서는 정답 칸을 비워 둔다.
3. 다 쓴 뒤 처음부터 다시 읽으며 **정답 칸을 채운다.**
   - 가능하면 다음 날 하는 게 좋다. 쓸 때의 의도보다 글에 실제로 적힌 내용을 기준으로 표시하게 되기 때문이다.
4. 파일을 저장해서 Claude에게 알려준다.
   - 정답은 AI를 돌리기 **전에** 확정한다.
   - AI 결과를 본 뒤에는 정답을 고치지 않는다. 고치면 시험 문제를 바꾸는 것이 된다.

## 1. 하지 말 것 (공정성)
- ❌ **ChatGPT, Claude 같은 AI로 메모를 쓰지 않는다.** AI가 쓴 글은 AI가 잘 맞혀서 점수가 부풀려진다.
- ❌ 프로젝트 폴더의 `prototype/prompts/`, `prototype/web/mock/`, AI 결과 파일을 열어 보지 않는다.
- ❌ "AI가 맞히기 쉽게" 혹은 "일부러 틀리게" 쓰지 않는다. **실제 주민센터 공무원이 바쁠 때 쓰는 메모**처럼 쓴다.
- ❌ 실제 사람의 이름, 주소, 전화번호, 주민번호를 쓰지 않는다. 지인의 실제 사정도 쓰지 않는다. 모두 지어낸 사람이어야 한다.

## 2. 메모 쓰는 법
- **길이:** 2~5문장(50~200자). 짧은 것과 긴 것을 섞는다.
- **말투:** 공무원 업무 메모체로 쓴다. "~함", "~하심", "~라고 함", "안내함" 같은 개조식 표현, 줄임말(수급, 차상위, 긴급복지, 주거급여, 기초연금), 오타 한두 개는 자연스럽다.
- **넣을 것:** 상담 날짜, 상담 방식(전화/방문/내방), 무엇을 안내했는지, 대상자 반응, 종결 여부
- **반드시 섞을 것:** 애매하게 말하는 사람, 말을 바꾸는 사람, 가족 얘기만 하다 끝난 상담처럼 깔끔하지 않은 사례
- 같은 사람을 두 번 상담한 경우(1차, 2차)를 **4쌍(8건)** 넣는다. 가구ID를 같게 쓰고 날짜는 몇 달 차이를 둔다. 4쌍 중 2쌍은 두 번 모두 같은 이유로 미루고, 1쌍은 미루긴 했지만 이유가 다르게(예: 1차는 서류, 2차는 건강) 쓴다.

**예시** (형식 참고용이며 이 문장을 그대로 쓰지 않는다):
> 2026.8.12 전화상담. 기초생활 안내드렸으나 "서류 떼러 다닐 형편이 안 된다"며 다음에 하겠다 하심. 문자로 자료 보내드리는 건 괜찮다 함. 자녀와 연락 안 한 지 오래됐다고. 상담안내 후 종결.

## 3. 상황 배분 (30건)
아래 개수는 대략적이다. ±1건 차이는 괜찮다.

| 상황 | 건수 | 예 |
|---|---|---|
| 신청을 미룸 (이유를 골고루: 서류·절차 3, 건강 2, 시간·생계 1) | 6 | "서류가 너무 복잡해서", "몸이 아파 다닐 수가 없어서", "일 때문에 시간이 없어서" 나중에 하겠다 |
| 뭐가 필요한지 본인도 불분명 | 4 | 하소연만 하다 끝남, 필요한 게 없다면서 어려움을 말함 |
| 위기가 일시적으로 해소됐다고 말함 | 4 | "일 다시 구했어요", "아들이 도와주기로 했어요" |
| 분명한 거부 | 5 | 신청은 싫다. 이 중 2건 이상은 "문자나 방문은 괜찮다"처럼 연락 범위가 갈리게 쓴다 |
| 아직 조사 중인데 종결처럼 적힌 메모 | 3 | "다음 주 재방문 예정", "소득 확인 후 다시 연락하기로" |
| 연락 불가·부재 | 3 | 전화 안 받음, 방문했는데 3번 부재, 우편물 쌓임 |
| 기준 초과·지원 제외 | 2 | 재산 기준 초과, 이미 다른 급여 수급 중 |
| 판단하기 정말 어려운 사례 | 3 | 여러 상황이 섞임, 말이 오락가락함 |

**골고루 넣을 요소:** 1인가구 / 가족 있음, 고립 징후(이웃·가족 왕래 없음, 우편물, 단전), 나이대와 성별(점수에는 쓰지 않지만 현실감을 위해 넣는다).

## 4. 정답 표시하는 법
메모에 **실제로 적힌 내용만** 기준으로 표시한다. 적혀 있지 않으면 "미확인"이다. 추측하지 않는다.

| 칸 | 고를 값 | 기준 |
|---|---|---|
| 업무상태 | 조사중 / 종결 / 판단보류 | 메모상 처리가 끝났는지. 다음 연락·방문 약속이 있으면 조사중. 정말 모르겠으면 판단보류 |
| 종결유형 | A / B / C / D1 / D2 / D3 / 없음 | A 기준초과, B 지원제외, C 조사불가(연락불가·부재), D1 정보만 받고 신청 미룸, D2 욕구 불명확, D3 위기 일시 해소. 종결이 아니면 "없음". D1은 미뤘다는 **결과**만 본다. 왜 미뤘는지는 아래 '장벽원인' 칸에 따로 적는다 |
| 장벽원인 | 서류·절차 / 건강 / 시간·생계 / 기타 / 해당없음 / 미확인 | 신청을 미루거나 못 한 **이유**. 서류가 복잡하면 서류·절차, 아파서 못 다니면 건강, 일하느라 시간이 없으면 시간·생계. 이유가 안 적혀 있으면 미확인. 신청을 미룬 경우가 아니면 해당없음 |
| 신청 | 동의 / 거부 / 보류(장벽) / 미확인 | 보류(장벽) = 하고 싶지만 형편상 미룸. 거부 = 하고 싶지 않음 |
| 문자 | 동의 / 거부 / 미확인 | 대상자 **본인**이 문자·자료 발송에 대해 밝힌 의사 |
| 방문 | 동의 / 거부 / 미확인 | 대상자 **본인**이 방문 상담에 대해 밝힌 의사. "다음 주 재방문 예정"처럼 **담당자의 계획만** 적혀 있으면 동의가 아니라 미확인 |
| 관계망부재 | 있음 / 없음 / 미확인 | 가족·이웃과 왕래 없음이 메모에 적혀 있으면 "있음" |
| 고립징후 | 있음 / 없음 / 미확인 | 우편물 적체, 반복 부재, 단전·단수 언급 등 |
| 근거문장 | (선택) | 판단 근거가 된 메모 속 구절을 복사해 둔다 |
| 메모 | (선택) | "판단이 애매했음" 같은 작성자 의견 |

## 5. 다 쓰고 확인할 것
- [ ] 30건이고, 가구ID가 같은 쌍이 4개 있다.
- [ ] 위 상황 배분과 대략 맞는다.
- [ ] 정답 칸이 모두 채워져 있다(근거문장, 메모 칸은 선택).
- [ ] 실제 인물 정보가 없다.
- [ ] AI 도움 없이 직접 썼다.
