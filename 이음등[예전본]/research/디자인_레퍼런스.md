# 이음등 디자인 레퍼런스 (2026-11-13 조사)

**5줄 요약**
1. 요청한 5개 갤러리 중 실제로 열린 곳은 awwwards, itsnicethat, cosmos(랜딩 한 장뿐)다. lapa.ninja는 403, pinterest는 본문 없음(제목만)이라 이 둘에서는 레퍼런스를 만들지 못했다.
2. 소개 페이지(A)용으로는 "종이 오리기·콜라주·따뜻한 손그림" 계열 사례가 잘 모였다(Amna 리브랜딩, Sara Hagale, Yuxing Li, Nanna Prieler 등).
3. 업무 대시보드(B)용으로는 갤러리에서 쓸 만한 사례가 적다. awwwards의 대시보드 사례는 템플릿이거나 마케팅 사이트다. B는 "차분한 구조와 타이포만 빌리고, 나머지는 우리 토큰으로 직접 정의"하는 것이 안전하다.
4. awwwards 상세 페이지는 팔레트 헥스·태그·수상 정보만 주고 실제 화면은 못 봤다. 아래 "확인" 표시는 열어본 페이지에 적힌 내용까지만 뜻하며, 화면 인상은 "미확인"이다.
5. 권장은 방향 2안 "종이 오리기 따뜻한 기록"이다. A는 편집·일러스트, B는 베이지 바탕에 램프 빨강을 경고 한 곳에만 쓴다.

## 2. 반대 증거와 한계

- awwwards는 화려한 모션·WebGL 중심 상이라, 업무 도구에 그대로 가져오면 가독성을 해친다. 대시보드 카테고리 상위 10개 중 다수는 템플릿 판매 페이지(예: Admin Dashboard Template)이고 공공 업무 화면의 참고가 되기 어렵다(https://www.awwwards.com/websites/dashboard/ 에서 확인).
- 비영리 컬렉션의 수상작 상당수가 2013~2016년 작품이라 현재 감각과 거리가 있다(https://www.awwwards.com/awwwards/collections/nonprofit-websites/ 에서 확인). 이 목록에서 "종이 오리기 + 따뜻한 베이지" 조합은 확인되지 않았다.
- 종이 오리기 정확 일치 사례는 Amna 한 건뿐이다. 나머지는 콜라주·스텐실·연필 등 인접 기법이다.
- 따라서 B(업무 대시보드)의 구체 레이아웃 근거는 이 조사에서 충분히 나오지 않았다. 아래 B 가이드는 조사 결과가 아니라 접근성 일반 원칙에 따른 설계 제안이며, 별도 검증 대상이다.

## 3. 시각 방향 3안

### 방향 1. 「오려 붙인 기록」(종이 오리기 편집 톤)
- 무드 키워드: 종이, 손, 오려 붙임, 은은한 그림자, 기록, 따뜻함
- 팔레트 힌트: 크림 #F6EFE3, 우드 갈색 #6B4A33, 짙은 잉크 #2B2118, 램프 빨강 #C8352B(경고·로고에만)
- 타이포 힌트: 제목 세리프(예: Noto Serif KR 또는 나눔명조 계열), 본문 Pretendard 계열 고딕
- 근거: 콘셉트(손이 감싸는 종이 가족·집)를 가장 직접 표현하고, 레퍼런스 1·2·3과 맞는다.

### 방향 2. 「차분한 현장 장부」(베이지 업무 톤, 일러스트는 최소)
- 무드 키워드: 장부, 마루, 정돈, 낮은 채도, 신뢰
- 팔레트 힌트: 베이지 #F3ECDF, 카드 #FFFBF4, 본문 #2B2118, 경계선 #D9CBB5, 램프 빨강 #B3261E(경고 1곳)
- 타이포 힌트: Pretendard 단일 계열, 숫자는 tabular 숫자, 제목은 굵기만 차이
- 근거: 8시간 업무 사용에서 가독성과 접근성이 최우선이다. 레퍼런스 12(회색 + 한 색 강조), 14(베이지 + 기관 신뢰)와 맞는다.

### 방향 3. 「색종이 콜라주」(채도 높은 콜라주 톤)
- 무드 키워드: 활기, 도형, 콜라주, 발랄함
- 팔레트 힌트: 크림 바탕에 머스터드·테라코타·청록 도형
- 타이포 힌트: 둥근 고딕 제목
- 근거: 레퍼런스 3·4처럼 눈에 띄지만 위기가구라는 무게와 공공기관 신뢰감에는 맞지 않아 비추천.

## 4. 추천: 방향 1 + 2 결합 (A는 방향 1, B는 방향 2)

- A(소개 페이지): 방향 1. 큰 숫자(206,966명, 5,616명)를 세리프 제목 + 종이 오리기 일러스트 장면 옆에 배치. 스크롤마다 램프가 한 칸씩 켜지는 정도의 절제된 모션(레퍼런스 8·11의 섹션 흐름).
- B(업무 대시보드): 방향 2. 본문 대비 4.5:1 이상 유지, 빨강은 "우선 재방문" 표시와 램프 아이콘 한 곳으로 한정, 점수 분해는 회색 + 빨강 한 색 막대(레퍼런스 12), 일러스트는 빈 상태·로그인 화면에만. 그림자·질감·모션 효과는 B에서 쓰지 않는다.
- 두 화면이 한 서비스로 보이게 하는 공통 요소: 크림/우드 팔레트, 램프 아이콘, 같은 고딕 본문, 같은 종이 오리기 가족 일러스트(A는 크게, B는 작은 빈 상태 컷).
