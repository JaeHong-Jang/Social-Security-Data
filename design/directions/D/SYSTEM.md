# 이음등 D안 — 편집 대장 + 오린 쪽지 + 서류철 탭 (통합 시스템)

한 문장: **"바탕과 구조는 편집 대장(C), 손이 닿는 물건만 종이(B), 분류와 결정은 서류철 문법(A)."**
세 스타일을 섞은 것이 아니라 역할로 나눈다. 한 요소는 한 문법만 쓴다.

## 1. 역할 분담
| 층 | 문법 | 쓰는 곳 | 안 쓰는 곳 |
|---|---|---|---|
| 구조 | C: 마스트헤드(상단 5px 굵은 선 + 이중선 + 번호 메뉴), 세리프 큰 숫자, 괘선만 있는 표 | 모든 화면의 뼈대, 표, 목록 | - |
| 물건 | B: 오린 가장자리 + 종이 그림자 3겹 + 클립 | Home 한정(가족 일러스트 1회, 먼저 볼 3가구 쪽지, KPI 조각) | 표, 폼, 긴 글, 상세 본문 |
| 분류·결정 | A: 인덱스 탭, 파란 도장, 링 구멍 | 상세 섹션 탭(회차별 메모·점수·조건 대조·기록), 대기열 단계 탭(긴급·주의·관찰·처리됨), 처리 결정 도장, 링 구멍은 상세 파일 시트에만 | Home, 대기열 행 |

## 2. 질감 허용 구역 (이 규칙이 핵심)
- **종이 구역(질감 허용):** Home의 일러스트 카드, 먼저 볼 가구 쪽지, KPI 조각, 상세의 "파일 시트" 테두리.
- **평평 구역(질감 금지):** 대기열 표, 상세의 메모 본문·점수·결정 폼, 메모 분석, 기록. 읽고 비교하는 곳은 괘선과 숫자 정렬만 쓴다.
- 기울기: 종이 조각은 최대 ±0.6도, 표·본문은 0도. 점멸·반복 모션 없음.
- 빨강: 긴급 가구의 램프 아이콘과 "긴급" 글자에만. 집 모양 띠에서는 긴급 집 지붕의 작은 점만. 도장은 빨강 금지(--primary 잉크).
- 화면당 질감 면적은 Home에서도 1/3 이하. 8시간 보는 대기열·상세는 질감 0에 가깝다.

## 3. 공통 규칙
- 단계 표시: 색 + 아이콘 + 글자. 긴급=램프, 주의=삼각형, 관찰=원.
- 숫자: 세리프 900 + tabular-nums, 오른쪽 정렬. 점수는 표 첫 열의 큰 숫자.
- 글: 라벨 위주, 문장 금지. "AI" 단어는 화면에 쓰지 않는다(필요하면 "초안", "로컬").
- 지역 표기는 `span.rg` 한 곳. 구 이름을 통일하거나 바꿔도 레이아웃에 영향 없음(생성 스크립트 `rg()` 한 함수). 제목·카드 구도는 구 이름에 기대지 않는다.
- 최소 글자 15px, 본문 16~18px. 터치 대상 44px 이상(390 화면).

## 4. 토큰 제안 (diff, 파일: `design/directions/D/tokens-d.css` / 적용 시 `design/tokens.css`에 합침)
```diff
 :root {
+  --fw-serif-display: 900;      /* 큰 숫자·제호·표제 전용 */
+  --fs-numeral-xl: 300px;  --fs-numeral-l: 64px;  --fs-numeral-m: 38px;  --fs-masthead: 34px;
+  --rule-ink:  var(--text);     /* 마스트헤드 5px, 표 머리 2px */
+  --rule-hair: #DCCDB0;         /* 표 행 사이 1px (장식 줄, 대비 기준 밖) */
+  --rule-top-w: 5px;
+  --paper-edge:  1px 1px 0 #E2D6C2;
+  --paper-under: 3px 4px 0 #EADBC3;
+  --paper-soft:  0 10px 14px rgba(60,40,20,.13);  /* 3겹 drop-shadow, 종이 구역 전용 */
+  --paper-tilt: .5deg;
+  --tab-bg: var(--wood-100);  --tab-bg-2: #E0C9A0;  --tab-edge: #BFA77C;  --tab-h: 36px;
+  --stamp-ink: var(--primary);  --stamp-w: 2px;  --stamp-rotate: -3deg;
+  --ring-hole: #E3D6BD;
 }
```
- `--font-serif`는 기존 값 그대로. 기존 주석의 "업무 화면 = 그림자·질감 없음"은 "종이 구역(Home 카드)만 예외"로 고친다.
- 대비: 새 글자색은 없다. 탭·도장 글자는 기존 `--text`·`--primary`(CR 6.79 vs --surface), 새 값(`--rule-hair`, `--tab-edge`, 종이 그림자)은 장식이라 글자·아이콘에 쓰지 않는다. 탭 배경 `#E0C9A0` 위 `--text` 글자 대비는 구현 시 재계산(대략 9~10 예상, 미검증).
